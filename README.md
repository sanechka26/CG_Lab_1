# CG Lab #1 — Основы 3D-графики

Лабораторная работа №1 по компьютерной графике. Реализован вариант №1 — **Куб** с использованием Vulkan API.

## Условие варианта

Построить 3D-объект «Куб», вывести его на экран с корректной проекцией, обеспечить динамическую смену проекции и трансформации объекта. Реализовать все дополнительные задания (на оценку 5).

## Стек технологий

- **Язык:** C++20
- **Графическое API:** Vulkan 1.1+
- **Библиотеки:**
  - GLFW — создание окна
  - ImGui — интерфейс
  - GLM — линейная алгебра
  - VMA (Vulkan Memory Allocator) — управление памятью
  - vk-bootstrap — инициализация Vulkan
- **Сборка:** CMake 3.20+

## Реализованные дополнительные задания

1. ✅ Переключение ортографической и перспективной проекции через ImGui
2. ✅ Слайдеры для позиции, поворота и масштаба фигуры
3. ✅ Анимация: движение по окружности, пауза/воспроизведение, скорость, радиус
4. ✅ Изменение цвета фигуры через `ColorEdit4`
5. ✅ Процедурные цвета вершин (по координатам в локальной системе), умножение на базовый цвет
6. ✅ Несколько объектов на сцене с отдельными `VkDescriptorSet` (до 5 кубов)

## Требования для сборки

- Visual Studio 2022 (или MSVC Build Tools)
- CMake ≥ 3.20
- Vulkan SDK ≥ 1.3 (с `glslc`)
- Git
